# Genshin Build Showcase

Here’s a ready-to-use prompt focused only on the UI/UX design, with strong emphasis on animation, transitions, responsiveness, and a premium Genshin-inspired feel:

Animated Genshin Build Viewer Hero UI Prompt

Design a stunning, premium, highly polished landing page hero section for a modern Genshin Impact character/build showcase website.

The design should feel like a high-end game interface mixed with modern Apple-level web design — cinematic, elegant, immersive, minimal, and extremely smooth. Do NOT make it look like a generic SaaS website.

Visual Direction

Use a dark fantasy aesthetic with a near-black background, subtle navy/indigo gradients, soft elemental colors, atmospheric lighting, glassmorphism, subtle glow effects, and cinematic depth.

The hero should immediately communicate:

Character builds

Genshin-inspired character showcasing

Powerful stats

Premium visual presentation

Modern technology

Use subtle elemental color accents such as Anemo teal, Hydro blue, Pyro red/orange, Electro purple, Cryo blue, and Geo gold. Keep the overall interface sophisticated rather than overly colorful.

Hero Layout

Create a full-screen responsive hero section.

Desktop:

Minimal floating navigation at the top

Logo on the left

Navigation links centered/right

Small theme/settings/profile controls

Large headline positioned toward the left

Character artwork as the primary visual focus on the right

Character artwork should partially extend beyond the hero container for depth

Floating stat cards surrounding the character

Subtle decorative UI elements behind the character

Strong visual hierarchy with plenty of negative space

Hero copy:

Small eyebrow:

"GENSHIN CHARACTER SHOWCASE"

Main headline:

"Your Builds.

Beautifully Revealed."

Supporting text:

"Showcase your characters, artifacts, weapons and stats in a cinematic profile built for Genshin players."

Primary button:

"View Your Builds"

Secondary button:

"Explore Showcase"

Character Presentation

Make the character artwork the visual centerpiece.

Use a large high-quality fantasy anime-style character composition with:

Soft rim lighting

Atmospheric glow

Floating particles

Elemental energy

Subtle depth-of-field

Cinematic shadows

Light rays

Very subtle parallax movement

The character should feel like it is emerging from the background rather than simply being placed on top of it.

Do not overcrowd the character with UI.

Floating UI Cards

Add elegant floating glass cards around the character.

Examples:

CRIT RATE

72.4%

CRIT DMG

218.6%

ENERGY RECHARGE

142%

Use:

backdrop blur

translucent dark backgrounds

thin borders

subtle gradients

soft shadows

tiny elemental accents

elegant typography

Cards should have slight floating animations and respond subtly to cursor movement.

Animation & Motion

Make the entire hero feel alive.

On initial page load:

Background fades in slowly.

Atmospheric particles appear with staggered timing.

Navigation fades/slides into position.

Eyebrow text fades upward.

Main headline reveals line-by-line with a smooth mask animation.

Supporting text fades upward.

CTA buttons scale/fade into place.

Character artwork smoothly slides upward and fades in.

Character glow expands subtly.

Floating stat cards appear one after another with spring-like motion.

Use premium motion similar to:

Framer Motion

GSAP

Apple website transitions

cinematic game UI animations

Animations should feel smooth and intentional, never bouncy or childish.

Use easing such as:

cubic-bezier

ease-out

spring with subtle damping

Avoid excessive animation.

Mouse Interaction

On desktop, add subtle cursor-based parallax.

When the user moves the mouse:

Character moves slightly in the opposite direction

Background gradient shifts subtly

Floating cards move at different depths

Particles react very slightly

Decorative elements rotate or shift by a few pixels

Keep the effect extremely subtle and premium.

Add a soft radial spotlight following the cursor.

Button Interactions

Primary CTA:

subtle glow

gradient border

smooth hover expansion

tiny arrow movement

background gradient animation

On hover:

button moves upward 2–3px

glow increases

arrow slides slightly right

Secondary CTA:

transparent glass style

border becomes brighter on hover

subtle background blur

Use smooth transitions around 250–400ms.

Background

Create multiple depth layers:

Layer 1:

Deep black/navy gradient.

Layer 2:

Large blurred elemental gradient behind the character.

Layer 3:

Very subtle radial spotlight.

Layer 4:

Tiny floating particles.

Layer 5:

Thin abstract energy lines.

Layer 6:

Very subtle grain/noise texture.

The background should feel atmospheric and expensive, not visually noisy.

Scroll Transition

At the bottom of the hero, create a beautiful transition into the next section.

Use:

fading particles

gradient blur

soft light streaks

curved atmospheric divider

As the user scrolls:

character slowly moves upward

background glow expands slightly

hero content fades subtly

next section smoothly emerges

Avoid abrupt section changes.

Mobile Design

The hero must be designed mobile-first and remain visually impressive on phones.

On mobile:

Compact navigation

Hero headline centered

Character artwork positioned below/behind the headline

Floating stat cards become smaller

Reduce decorative elements

Preserve the cinematic atmosphere

CTA buttons become full-width or stacked

Prevent horizontal scrolling

Keep text highly readable

Ensure the character never covers important text

The mobile version should feel intentionally designed, NOT like a desktop layout squeezed into a phone.

Typography

Use a premium modern sans-serif font.

Typography should have:

large bold display headline

tight letter spacing

strong contrast

clean body text

subtle uppercase labels

Main headline should be the strongest visual element after the character.

Use text gradients sparingly for emphasis.

UI Details

Add tiny premium details:

glowing 1px borders

micro-interactions

subtle animated gradient lines

tiny status indicators

minimal decorative symbols

soft shadows

glass reflections

subtle noise texture

Everything should have generous spacing.

Overall Experience

The final result should feel like:

"Genshin Impact character showcase meets premium modern interactive website."

It should look cinematic, futuristic, elegant, immersive and expensive.

Prioritize:

Visual impact

Smooth animation

Typography

Character presentation

Responsive design

Micro-interactions

Performance

Avoid:

Generic SaaS layouts

Excessive glassmorphism

Excessive neon

Excessive gradients

Huge amounts of text

Cheap-looking animations

Excessive rounded cards

Cluttered UI

Constant motion

Cartoonish UI

The final hero should make the user immediately think:

"This looks insanely good."
